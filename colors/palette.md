# Horizon Color Palette

Light theme inspired by **Trails beyond the Horizon** (Kai no Kiseki Edition).
Colors based on the crossover protagonists and artifacts.

## Character Colors

| Character | Hex | Usage |
|-----------|-----|-------|
| **Van Arkride** | `#1E3A5F` | Primary, functions, links (PROMINENT) |
| **Kevin Graham** | `#1C5E24` | Strings, success (PROMINENT) |
| **Rean Schwarzer** | `#4A423B` | Properties, attributes (PROMINENT) |
| **Agnès Claudel** | `#8C0F45` | Keywords, control flow |
| **Emilia** | `#5C3A00` | Constants, numbers (darkened for light theme) |
| **Grandmaster** | `#571583` | Decorators, annotations |
| **Laegjarn's Chest** | `#00473E` | Types, classes, info (darkened for light theme) |
| **Horizon** | `#8A3100` | Warnings, deprecated (darkened for light theme) |
| **Aaron Wei** | `#9E1C1C` | Errors, danger |
